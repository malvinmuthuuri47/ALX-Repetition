## 0x01. ES6 Promises

### Learning Objectives
#### At the end of this project, you are expected to be able to [explain to anyone](https://savanna.alxafrica.com/rltoken/Z4xW7_BFaRcrHxfDySjKuQ), **without the help of Google**:
* Promises (how, why, and what)
* How to use the <span color='red'>then</span>, <span color='red'>resolve</span>, <span color='red'>catch</span> methods.
* How to use every method of the Promise object.
* Throw/try
* The await operator
* How to use an <span color='red'>async</span> function

> [!NOTE]
> ### Requirements
> * All your files will be executed on Ubuntu 18.04LTS using NodeJS 12.11.x
> * Allowed editors: <span color='red'>vi, vim, emacs, Visual Studio Code</span>
> * All your files should end with a new line
> * A <span color='red'>README.md</span> file, at the root of the folder of the project is mandatory
> * Your code should use the <span color='red'>js</span> extension
> * Your code will be tested using <span color='red'>jest</span> and the command <span color='red'>npm run test</span>
> * Your code will be verified against lint using ESLint
> * All your functions must be exported

> [!IMPORTANT]
> ### Task Descriptions
> * **Task One** - Writing a function that returns a Promise
>* **Task Two** - Writing a function that returns a Promise that resolves into an object or an error that returns a string message
> * **Task Three** - Writing a function that returns a Promise that resolves into an object, an error object when it rejects, and a message logged to the console whether the promise resolves or it rejects.
> * **Task Four** - Writing a function that collectively resolves all promises passed to it and logs the results of the resolutions to the console.
> * **Task Five** - Writing a simple function that returns a resolved promise with an object
>* **Task Six** - Writing a function that returns a Promise rejecting with an error and a string message.
> * **Task Seven** - Writing a function that resolves all promises and uses the Promise.allSettled() method to return an array of objects
> * **Task Eight** - Writing a function that returns the value of the first promise that resolves the first
> * **Task Nine** - Writing a function that divides a numerator by a denominator and throws an error with a message when the denominator is equal to 0
> * **Task Ten** - Writing a function that creates and returns an array that's appended with the results of a function that's passed to it, whether its a value or an error.
